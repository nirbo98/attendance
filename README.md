# דף רישום נוכחות

דף סטטי שהסטודנטים מגיעים אליו כשהם סורקים את הקוד שעל המקרן.

הדף לא מכיל נתונים, סודות או רשימות. כל הבדיקות והשמירה נעשות בשרת Apps Script של המרצה, בגיליון שלה. הכתובת של אותו שרת מגיעה בתוך הקוד שעל המקרן (הפרמטר `k`), ולכן אותו דף משרת כל מרצה שמשתמשת במערכת.

אם הדף הזה לא זמין, במסך המרצה יש מעבר לדף הגיבוי שרץ ישירות ב-Apps Script.
